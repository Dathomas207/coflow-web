Modes

Observe, then comment, then enforce.

An agent in observe mode records findings and never blocks anyone. Comment mode posts them on the pull request. Enforce mode fails the check when a required rule is broken. You set a target mode, a minimum severity, a cap on findings per run, and whether findings appear inline.

Agents never merge. The change control pack includes the rule that says so.

The review engine

Seven steps on every pull request.

  1. 1
    ScopeLoad only the rules that apply to the changed files
  2. 2
    CoverageReport changed files that no rule or check covers
  3. 3
    Static checksMap linter and scanner results onto rules
  4. 4
    Rule reviewAn AI review of the diff against each rule that asks for one
  5. 5
    VerificationEach finding must quote the changed lines, or it is dropped
  6. 6
    TicketCheck that the change links the ticket that authorized it
  7. 7
    DispositionComment, annotate or fail the check, according to the agent's mode

A finding that cannot point to the lines it is about never reaches your pull request.
