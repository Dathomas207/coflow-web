Agents

One rulebook. Every agent your team uses.

CoFlow does not replace your coding agents. It gives each of them the same reviewed set of rules, in the format that agent already reads, so a change made in Cursor meets the same standard as one made in Claude Code.

How a rule reaches an agent

Approve once. Every agent gets it.

  1. 1

    One source of truth

    Each rule is a small file in your repository, with a scope and the evidence it came from.

  2. 2

    Compiled per agent

    CoFlow writes the approved rule out in the format each agent reads. Nobody maintains four copies.

  3. 3

    Loaded only when relevant

    Rules are scoped by path and technology, so a migration rule stays out of a CSS change and context cost stays flat.

  4. 4

    Kept in sync

    A required check fails if an agent's files drift from the approved rules.

Mixed teams

Let each developer keep the agent they like.

Standardizing on one agent is a hard conversation and a short-lived decision. CoFlow makes the choice of agent a personal one and keeps the standard a team one.

Four agents alone

  • Four rule files, maintained by hand.
  • Each one drifts from the others.
  • Review catches what the context missed.

Four agents with CoFlow

  • One approved set of rules.
  • Written out for each agent automatically.
  • Adherence graded the same way for all four.
