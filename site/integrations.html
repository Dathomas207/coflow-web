Approvals in chat

Review a proposal without leaving Slack or Teams.

CoFlow posts proposal cards, scorecards and agent run summaries to the channel you choose. Approving in chat records the decision; the rule becomes active when its pull request merges. Text from people and repositories is redacted and escaped, and a card is never sent if it contains a secret.

Trackers

Tickets as evidence, and as authorization.

01Evidence for rulesBugs and incidents in Jira or Linear explain why a rule exists. Each rule links the tickets behind it.
02Authorization for changesThe review engine checks that a pull request links the ticket that approved it, as change control requires.
03Data, not instructionsTicket text is read as data and never followed as an instruction by any model.
