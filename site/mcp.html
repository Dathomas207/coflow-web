What an agent can ask CoFlow.

ToolWhat it doesAccess
get_standardsThe rules that apply to the files and frameworks in a task, cut to a token budgetRead
list_rules, get_ruleBrowse the approved rules and read one in fullRead

get_system_context, where_isWhere a service, datastore or dataflow lives, and how to reach itLocal
impact_ofWhat else a change to these paths can affectLocal
get_playbooksWhen to reach for another system, such as the logs or the cloud console, and howLocal
remember, correct, forgetStore, fix or drop a project fact so no later session has to find it againLocal
propose_contextTurn learned facts into a reviewed change to the system mapLocal

There is no approve tool. An agent can propose a rule or a fact; only a person can make it active. Tools marked Local run on the stdio server today.

Hosted service security

Built to be pointed at your code.

01Off until you turn it onThe service refuses to start unless it is enabled with authorization required. There is no anonymous mode.
02Identity from the token onlyEvery request needs a bearer token, checked on every call. Tool inputs cannot carry an organization or user, and inputs that try are rejected.
03Scoped and switchableRead and write scopes per token. An admin can switch a tool off for an organization, and it disappears from discovery.
04Budgets on every callerCalls are limited per person and per organization, per minute and per day, with bounded input and output sizes.
05Logs without contentOne line per call: tool, hashed organization, duration and outcome. Arguments and results are never logged.
06Declared fields onlyResponses carry only the fields in the published contract, so nothing extra can leak through.
Command line

The same engine in your terminal and CI.

  1. 1

    init and scan

    Detect the stack from your manifests, propose the matching packs and write the agent files.

  2. 2

    compile

    Print the rules an agent gets for a set of paths, cut to the token budget.

  3. 3

    export --check

    Fail CI when a generated agent file no longer matches the approved rules.

  4. 4

    check and inbox

    Review a diff against the rules, and work through corrections captured at the end of agent sessions.
