Use case: security

Ship fast without shipping the next incident.

Agents reach for the shortest path, and the shortest path is often the insecure one. CoFlow puts OWASP, CWE and your own security lessons in front of every agent, then checks the result on the pull request.

See it work

The same request, with and without your standards.

RequestAdd a sign-up endpoint that stores the password.

Agent aloneauth.py
def create_user(email: str, password: str, db):    digest = hashlib.sha256(password.encode()).hexdigest()    logger.info(f"new user {email} {password}")    db.add(User(email=email, password_hash=digest))    db.commit()
  • CWE-916A fast hash with no work factor for passwords.
  • CWE-759No salt, so equal passwords share a hash.
  • CWE-532The plain password is written to the log.
With CoFlowauth.py
ph = PasswordHasher() def create_user(email: str, password: str, db):    digest = ph.hash(password)    logger.info("new user", extra={"user": email})    db.add(User(email=email, password_hash=digest))    db.commit()
  • CWE-916Argon2 with a memory-hard work factor.
  • CWE-759A unique salt per hash, handled by the library.
  • CWE-532The log carries the user, never the secret.

Starter standards

The rules a security review would ask for, before the review.

01Passwords use a memory-hard hashArgon2 or bcrypt through a maintained library. Never a general-purpose hash.
02Secrets come from the vaultNone in code, config files or logs.
03Parameterized queries onlyNo query is built by joining strings with user input.
04Every lookup is scopedRecords are read through the caller's tenant and permissions.
05Dependencies are pinnedVersions are locked and new packages are reviewed before merge.
06Errors leak nothingResponses carry an id, not a stack trace or a query.
Beyond the starter set

Security findings become rules, and rules become evidence.

AFindings become rulesA scanner finding, a pen test note or an incident ticket is evidence. CoFlow drafts the rule and your team approves it.
BDeviations on the recordWhen a rule has to be broken, the rule, the reason and the approver are logged.
CEvidence for auditsEvery merged change is graded against the rules that applied. Using CoFlow is not a certification of compliance.
