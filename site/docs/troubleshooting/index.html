Troubleshooting

Start with the boundary that is blocking the workflow.

I can sign in but cannot open a project

Have an administrator check your active membership, your current identity provider membership, your role and your project assignment. Signing in is not enough. Do not work around it by adding a tenant ID to a request header.

Billing required

Under the planned billing model, credit-using work needs an active trial or subscription. If the trial ended without converting or a payment failed, ask an owner of your organization to check billing. Deterministic features (rules, compiled context, MCP, host checks and linters) do not depend on credits.

Out of credits

A run that would cost more than the balance is refused before it starts, not run halfway. Wait for the monthly allowance, buy a credit pack or turn on auto top-up with a monthly cap. Failed runs are refunded. See credits and usage.

A tool shows “not run”

Read the reason. “Tool not installed” means the binary was not found locally or on the hosted worker. The hosted worker runs only ruff, bandit, zizmor, actionlint and hadolint, and only on files it can rebuild whole from the patch. mypy, cppcheck and clang-tidy never run on the server. A tool may also be turned off under tools: in .coflow/config.yaml at the base commit. Run coflow tools locally, and see review and tool checks.

An agent is blocked by the autonomy ceiling

Merge, approve, push, force-push and bypass are refused at every level. A flow that contains one of them does not load; remove that step. If an action waits instead, it needs a person: check Needs you, the agent’s level and its binding’s level. A run uses the most restrictive of those levels.

An approval is stuck

A request is blocked when its quorum cannot be reached by eligible people. It is never lowered silently. Add an eligible reviewer, adjust the policy, or ask an owner to break glass where the policy allows it. Approvals made before the content changed no longer count.

Compilation drops or shortens rules

Read the response: it names rules that were shortened, deferred or dropped to fit the budget. Raise the budget, narrow the paths, or use get_rule for the full text.

An integration is unavailable

Check that your deployed release contains the integration, that it is turned on for your organization, and that its credentials and any scheduled jobs are set up. A stored connection alone does not prove an integration is active. Many vendor integrations have not been verified against live accounts yet; see Connect and feature status.

Rows disappear after enabling RLS

Confirm ownership backfill, transaction-local organization and project scope, and the restricted runtime role. Verify in a disposable environment. Never disable production policies to make a query return rows.

Ask for help

Send the module, the error code, the approximate time and your deployed version to support@getcoflow.ai. Do not include tokens, personal data or private source code.
