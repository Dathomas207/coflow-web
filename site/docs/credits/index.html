Credits and usage

What credits pay for, what never uses them, credit packs and how usage is shown.

Status

Planned launch billing model. This page describes the billing model being built for launch. It is not live: CoFlow is in private build, nothing on this website takes payment, and the values below are proposed starting values that may change before launch.

What credits pay for

  • Evaluations: harness and dataset runs that call a model.
  • Lessons: drafting rule proposals from evidence and testing them.
  • Agent runs: sandbox, shadow and live runs in Agent Studio.
  • Model-backed review: review steps that need a model.

What never uses credits

Deterministic features never use credits and keep working when the balance is zero: rules and rule packs, compiled context, the MCP server, host checks, and the linters and scanners CoFlow runs.

Monthly allowance

Credits

Monthly credits do not roll over to the next month.

Credit packs

One credit is worth $0.01. Packs add credits on top of the monthly allowance:

$505,000

$1,000100,000
  • Pack credits expire 12 months after purchase.
  • Auto top-up is optional. When it is on, it buys a pack when the balance runs low, up to a monthly cap you set.

How a run is charged

  • Cost before the run: CoFlow shows what a run will cost and reserves the credits before it starts.
  • Failed runs: credits for a run that fails are refunded.
  • Low balance: when the balance cannot cover a run, the run is refused rather than started and left half done.

Seeing your usage

A usage meter in the app shows the balance and what has been used this month. The Usage page breaks usage down and exports it as CSV.

Credits are separate from the cost ledger, which records the tokens and runner minutes your own coding agents and models use, priced with your own contract prices. Your coding-agent subscriptions are also separate.
