Documentation / Core features

Workflow Studio

Turn self-contained HTML prototypes into reviewed, editable workflow evidence.

Upload and capture

Upload self-contained HTML pages and select an entry page. Playback uses an opaque-origin sandbox. Record interactions, form validation, error states and in-bundle navigation. Captures are validated and converted into workflow state graphs.

Edit, review and link

Relabel and annotate states or transitions, and add clearly marked manual steps. Each save creates an immutable revision. Authorized reviewers approve or reject revisions. Links to requirements and bugs pin the workflow revision, capture and source provenance.

Replay and export checks

Replay the trace and compare settled states. Export a Playwright test using stable locators where available. Unstable selectors are flagged with suggested test IDs. Unreviewed exports carry a warning; review them before adding them to monitoring.

Evidence and isolation

Replay results are client-reported, not independent server verification. Uploaded HTML is untrusted and cannot run in the application origin. The sandbox blocks many external interactions, but it is not a fully network-isolated server-side browser. Use synthetic input and avoid entering secrets into prototypes.

Workflow records use organization ownership, project authorization and forced PostgreSQL RLS. Read the isolation guide.
