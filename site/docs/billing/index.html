Documentation / Plans and usage

Plans, credits and prepaid usage

Understand included credits, Business security features and usage expansion.

Monthly allowance

The proposed Team and Business offers each include approximately 1,000 credits per month. Credits cover supported CoFlow evaluations, automatic lesson generation and code scans. Lesson generation produces review candidates; it does not approve its own guidance.

Credit allowance scope, reset timing, expiry and rollover terms must be confirmed during onboarding. Do not assume 1,000 operations or 1,000 credits per agent or seat.

Prepaid top-ups

Additional usage is intended to use prepaid credit top-ups. Credit consumption reflects the selected workload, model and input/output token usage. Agent count helps plan demand; it is not itself a published credit conversion rate.

Credit-pack prices and operation weights have not been published. The public website prepares enquiries; it does not sell or activate top-ups. Confirm rates, funding arrangements and spending controls before purchasing.

Business security

Business includes single sign-on (SSO) and SOC 2 Type II audit support as part of the commercial offer. SSO requires provisioned identity configuration and the appropriate deployed release. Audit support covers readiness and evidence workflows; these docs do not assert an issued SOC 2 Type II report.

Visit the Trust Center for the current access documentation, or read RLS and tenant isolation.

Billing implementation and activation

The source includes versioned catalogs, usage events, entitlement checks, operation deduplication and separate model input/output token meters. Measured usage is distinct from charged usage. These foundations do not mean that the new 1,000-credit offer, conversion rates or top-up purchases have been activated.

Production billing needs a configured catalog and provider, approved prices/allowances and verified release controls. This website update changes the offer language, not the application’s billing configuration.

Plan your usage budget

  1. Estimate monthly evaluations, lesson-generation jobs and code scans.
  2. Identify the agents/models used and their expected input/output tokens.
  3. Apply the published credit rate for each workload once available.
  4. Choose prepaid capacity and confirm the spending limit before running additional paid work.
