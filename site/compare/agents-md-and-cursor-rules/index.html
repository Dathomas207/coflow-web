CoFlow vs rules files

CoFlow vs AGENTS.md and Cursor rules: one source, every agent.

A hand-written AGENTS.md, CLAUDE.md or Cursor rules file is the right place to start. CoFlow is what teams move to when one file per tool stops scaling.

Choose rules files if

  • You are one or two developers on a single coding agent.
  • You have a short list of conventions that rarely changes.
  • You do not need to know whether the rules are followed.

Choose CoFlow if

  • Your team uses more than one coding agent.
  • The rules file has grown long, and nobody reviews what goes into it.
  • You want rules scoped to the task, checked on the pull request and measured.

Using both

CoFlow writes the files you already use.

You do not give up AGENTS.md, skills or Cursor rules. CoFlow generates them from the approved rule set and a required check fails if they drift, so the files stay current without anyone maintaining four copies.

Questions

Common questions.

What is AGENTS.md?

AGENTS.md is a plain Markdown file in a repository that tells coding agents how to work in that codebase. Several agents read it, including Codex.

Can CoFlow import our existing AGENTS.md or Cursor rules?

CoFlow reads your existing code, reviews and tickets and proposes rules from them. Your current rule files are a good starting point for the first set.

Do the generated files conflict with ones we edit by hand?

CoFlow owns the generated files. Keep hand-written guidance in the rule set so every agent gets it.
