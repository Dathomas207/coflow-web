Use case: infrastructure as code

Infrastructure that passes the first review.

An agent will happily make a bucket public to get a demo working. CoFlow holds Terraform changes to your cloud baseline and flags risky commands before they run.

Talk to usTry the playground
See it work

The same request, with and without your standards.

RequestAdd a bucket for customer exports.

Agent aloneexports.tf
resource "aws_s3_bucket" "exports" {  bucket = "acme-exports"} resource "aws_s3_bucket_acl" "exports" {  bucket = aws_s3_bucket.exports.id  acl    = "public-read"}
  • Cloud baselineThe bucket is readable by anyone on the internet.
  • Tagging ruleNo owner or cost center tags.
With CoFlowexports.tf
resource "aws_s3_bucket" "exports" {  bucket = "acme-exports"  tags   = local.required_tags} resource "aws_s3_bucket_public_access_block" "exports" {  bucket                  = aws_s3_bucket.exports.id  block_public_acls       = true  block_public_policy     = true  ignore_public_acls      = true  restrict_public_buckets = true}
  • Cloud baselinePublic access is blocked on the bucket.
  • Tagging ruleThe required owner and cost center tags are applied.
Where the rules came fromYour cloud baseline, plus one incident ticket about an exposed bucket.

Starter standards

The baseline your platform team would hold every change to.

01No public storageBuckets and blobs block public access unless an exception is approved.
02Encrypted at restEvery data store has encryption on, with keys you manage.
03Least privilegeRoles get the permissions the service uses, never wildcards.
04Every resource is taggedOwner, environment and cost center on everything that bills.
05State is remote and lockedNo local state files and no concurrent applies.
06Changes are planned firstAn apply runs only from a reviewed plan.
Beyond the starter set

Guardrails where agents can do real damage.

ARisky commands need a personDestroys, force pushes and production applies are blocked or need confirmation, and every decision is logged.
BExceptions on the recordA public bucket that has to be public gets a logged exception with a reason and an approver.
CDrift on the scorecardThe scorecard shows which baseline rules hold across every merged change.
