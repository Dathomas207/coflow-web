Use case: applications

Back ends that read like one team wrote them.

Every agent has its own idea of how an endpoint should look. CoFlow turns your conventions for routes, queries, errors and tests into rules, so the hundredth endpoint looks like the first.

See it work

The same request, with and without your standards.

RequestAdd an endpoint that lists orders with the customer name.

Agent aloneorders.py
@router.get("/orders")def list_orders(db=Depends(get_db)):    orders = db.query(Order).all()    return [{"id": o.id, "customer": o.customer.name} for o in orders]
  • Team ruleEvery row in the table is returned in one response.
  • SQLAlchemy standardOne extra query per order to load the customer.
  • FastAPI standardNo response model, so the shape is undocumented.
With CoFloworders.py
@router.get("/orders", response_model=Page[OrderOut])def list_orders(    cursor: str | None = None,    limit: int = Query(50, le=200),    db=Depends(get_db),):    q = select(Order).options(selectinload(Order.customer))    return paginate(db, q.order_by(Order.id), cursor, limit)
  • Team ruleCursor pagination. Default 50, maximum 200.
  • SQLAlchemy standardCustomers load in one query with the orders.
  • FastAPI standardThe response model documents and limits the fields.
Where the rules came fromThree review comments on earlier pull requests, plus the rules keyed to the frameworks this repository uses.

Example. Rule labels name the standard or team rule each finding maps to.

Starter standards

Conventions your senior engineers would enforce.

01Every list is paginatedCursor pagination with a default and a maximum page size.
02Relationships load on purposeNo lazy loading inside a loop. Eager-load what the response needs.
03One error shapeEvery error returns the same envelope with a code, a message and an id.
04Every route has a modelRequest and response models are declared and versioned.
05Tests ship with the changeA new route comes with a test for the success path and one failure.
06Migrations are reversibleEvery schema change has a working downgrade.
