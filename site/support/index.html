Before you write

Send these and we can start right away.

  1. 1

    Where it happened

    The organization and repository, and the pull request or check link if there is one.

  2. 2

    Which rule and which agent

    The rule file name and whether the agent was Claude Code, Codex, Cursor or Copilot.

  3. 3

    What you expected

    What you expected to happen, what happened instead, and when it started.

  4. 4

    Leave out secrets

    Do not paste keys, passwords or tokens. We will never ask for them.

02What we askTest only against accounts you own, avoid touching other customers' data, and give us reasonable time to fix the issue before you disclose it.

Common questions

Quick answers.

Policies are in the privacy policy and the terms of service.

How do I remove CoFlow's access to a repository?

Remove the repository in CoFlow, or uninstall or revoke the CoFlow app in your code host. Access stops immediately, and rules already in the repository stay where they are.

A rule is not showing up in my agent.

Check that the rule is approved and merged, that the file you are editing matches the rule's path scope, and that the sync check on your last pull request passed. If it still does not load, send us the rule file name and the agent you use.

Can I turn off a check for one pull request?

Yes. An approver can record an exception with a reason. It is logged and shows on the scorecard.

How do I delete our data?

Email privacy@getcoflow.ai from an account owner address. After a subscription ends, data is deleted within 60 days by default.
